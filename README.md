# CS2114 Project 1 — Group 3

Single-player Blackjack console game for CS2114.

## Requirements

- Windows
- Java installed and available on your `PATH`

## Compile

The project is precompiled. If you need to rebuild from source:

```bash
javac -d bin src/Blackjack/*.java
```

## Run

Double-click **[Run Game.bat](Run%20Game.bat)**, or from the project root:

```bash
Run Game.bat
```

## How to play

1. Load an existing save or create a new one and enter your name.
2. Place a bet (cannot exceed your balance).
3. Hit or stand to play your hand against the dealer.
4. Enter `quit` during a round to exit; your balance is saved (the current bet is forfeited).
